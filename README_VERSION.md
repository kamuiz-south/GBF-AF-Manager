# Version Updater (`set_version.bat`)

アプリのバージョン（マネージャー、拡張機能、Tauriアプリ）を安全かつ一括で更新するためのスクリプトです。

このバッチファイルを使用することで、手動で複数のファイルを探索・修正する手間と、書き換え漏れによるバージョン不一致のミスを防ぐことができます。

## 使い方

コマンドプロンプト（または PowerShell）を開き、プロジェクトのルートディレクトリ（このファイルがある場所）で以下のコマンドを実行します。

```cmd
set_version.bat <新しいバージョン番号>
```

**実行例:**
```cmd
set_version.bat 1.0.7
```

> [!NOTE]
> エクスプローラーのアドレスバーに `cmd` と入力してEnterを押すと、そのフォルダをカレントディレクトリとしたコマンドプロンプトを簡単に開くことができます。

## 更新されるファイル

スクリプトを実行すると、以下の5つのファイルの中にあるバージョン情報が一括で書き換わります。

1. `af-manager/package.json` （フロントエンドの設定）
2. `af-manager/src-tauri/tauri.conf.json` （Tauriアプリの設定）
3. `af-manager/src-tauri/Cargo.toml` （Rustバックエンドの設定）
4. `af-manager/src/App.tsx` （画面左下に表示されるテキスト）
5. `af-collector/manifest.json` （Chrome拡張機能の設定）

処理の完了後、どのファイルが書き換えられたかがコンソールに表示されます。
書き換えが成功したら、通常通り `build.bat` を実行して新しいバージョンのアプリをビルドしてください。

## 注意事項
- バージョン番号は `1.0.7` のような「数字.数字.数字」の形式（セマンティックバージョニング）で入力してください。
- 各ファイルに手動で不正な変更が加えられていると、正規表現による置換が失敗する場合があります。その場合はエラーメッセージが表示されます。
